# FreeRouter

> One API for free AI providers.

I wanted a simple way to experiment with multiple free AI providers without constantly switching APIs or deciding which provider was the best fit for a request.

So I'm building **FreeRouter**—an open-source AI gateway that intelligently routes requests across free AI providers through a single OpenAI-compatible API.

The goal is simple: integrate once and let FreeRouter handle provider selection, failover, rate limits, and API differences.

## Planned Features

- OpenAI-compatible API
- Smart provider routing
- Automatic failover
- Streaming support
- Provider health monitoring
- Unified model aliases (`free:auto`, `free:fast`, etc.)
- SDK & CLI
