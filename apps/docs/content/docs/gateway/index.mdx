`@freerouter/gateway` is a self-hosted server that wraps `@freerouter/sdk` in a deployable package. It exposes OpenAI-compatible `/v1/chat/completions` and `/v1/models` endpoints, stores your free-provider API keys **encrypted at rest**, issues *gateway keys* so clients never see provider secrets, and ships a bundled web dashboard for management and analytics.

## Why a gateway?

- **One key for clients.** Issue a `fr-live-...` gateway key; clients use it instead of provider keys. Provider secrets stay server-side and encrypted.
- **Bring your own free keys.** Connect Groq, Google, OpenRouter, and more — the gateway routes to them at $0 cost.
- **Dashboard + analytics.** Manage providers, keys, and watch usage from a local web UI.
- **OpenAI-compatible.** Any OpenAI SDK client works by pointing `baseURL` at the gateway.

## Packages

| Package | Description |
| ------- | ----------- |
| `@freerouter/sdk` | Core routing SDK (BYOK, failover, alias resolution). |
| `@freerouter/api` | Stateless Hono server exposing OpenAI-compatible endpoints. |
| `@freerouter/gateway` | Self-hosted gateway: SDK + encrypted key storage + dashboard + analytics + gateway-key auth. |
