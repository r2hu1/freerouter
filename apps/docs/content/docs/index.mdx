FreeRouter routes LLM requests across 13 free model providers - all at $0 cost - with automatic failover, per-key health isolation, and OpenAI-compatible HTTP endpoints.

## Packages

| Package           | Description                                                                                       |
| ----------------- | ------------------------------------------------------------------------------------------------- |
| `@freerouter/sdk` | Core SDK - model registry, alias resolution, health tracking, failover LanguageModelV4 wrapper    |
| `@freerouter/api` | HTTP API - Hono server exposing OpenAI-compatible `/v1/chat/completions`, `/v1/models`, `/health` |
| `@freerouter/gateway` | Self-hosted gateway - SDK + encrypted key storage + dashboard + analytics + gateway-key auth (run via `npx @freerouter/gateway serve`) |
| `@freerouter/db`  | Database-backed health stores (coming soon)                                                       |
